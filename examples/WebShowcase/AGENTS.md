# WebShowcase Reference Application

`examples/WebShowcase` is the reference implementation demonstrating generic `uppsrc/WebFramework` capabilities:
- Scalable multi-category **Mega-Menu** navigation.
- Decoupled **Templates** (MegaMenu, Dashboard, AppWorkspace) with configurable padding densities.
- KDE Plasma **Vivid Themes** (Dark & Light) and procedural WebAudio sound cues.
- Component showcase and semantic JSON endpoints for SweAgent.

## Running

```bash
# Build
uppbuilder examples/WebShowcase -v

# Run on port 8081
./bin/WebShowcase -p 8081
```
