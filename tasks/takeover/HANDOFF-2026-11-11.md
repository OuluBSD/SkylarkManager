## 3. The generic meta-auth app ("Google login" equivalent)

`uppsrc/MetaAccount` + the MetaAccount package **is** the meta-auth app:
- Ecosystem identity: one account per person across all fenced webapps.
- Sign-in: password (WebAuth PBKDF2) + **real TOTP** second factor with
  single-use recovery codes.
- **Consent grants**: a client webapp requests scopes (`science.author`,
  `taskfoundry.submit`, …); the user approves on the meta-account site;
  grants are caller-bound (usable only by the subject's own session) and
  revocable. This is the ecosystem's internal OAuth-like consent flow —
  deliberately not real OAuth yet.
- Broker service: `authenticate`, `request-consent`, `check-grant`,
  `revoke-grant` — how other sites consume identities and scopes.

**Not done yet**: composing the MetaAccount **site** into the real host
process (the installer exists; consent is currently operator-CLI:
`approve-taskfoundry-grant`). See BACKLOG item 6.
